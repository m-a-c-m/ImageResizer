# Image Resizer — Free Online Tool

**Image Resizer.** Resize JPG, PNG and WebP images in batch by percentage or max dimension. Download as ZIP. 100% in your browser. No sign-up, no ads, 100% client-side.

🌐 **Demo en vivo / Live demo:** [miguelacm.es/tools/image-resizer](https://miguelacm.es/tools/image-resizer)

## ✨ Features

- **📐 Batch resize:** Resize many images by percentage or by longest-side pixels, keeping the aspect ratio.
- **🔒 100% private:** All processing happens locally in your browser. Nothing is uploaded.
- **📦 ZIP download:** Download all resized images at once in a single ZIP file.

## 🚀 Quick start

```bash
git clone https://github.com/m-a-c-m/ImageResizer.git
cd ImageResizer
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Environment variables (optional)

```env
NEXT_PUBLIC_SITE_URL=https://miguelacm.es/tools/image-resizer
NEXT_PUBLIC_EMBED_URL=https://miguelacm.es/embed/image-resizer
```
